# Close Change

1. 运行 capabilities、status 和 evidence。
2. 确认 design approval current、tasks 完成、AC 全 PASS、semantic review 为 pass。
3. 向人类呈现实现证据、语义一致性与残余风险。
4. 只有人类在当前会话明确验收后，记录 completion approval。
5. 确认 completion approval current，再运行 `change archive <id>`。
6. 报告 reviewer、design/completion digest 和归档路径。
7. 规则细节以 `references/change-pack-contract.md` 为准。
